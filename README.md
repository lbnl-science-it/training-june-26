# training-june-26
**Clone this repo for the NRP hands-on**

This training session introducing new AI, ML, and distributed computing tools available to the LBNL research community.

Whether you are looking to scale your Python workloads, leverage AI for terminal assistance, or tap into global Kubernetes computing resources, this session will provide you with the practical knowledge to get started.

Event Details:

Date: June 10th, 2026
Time: 10:30 AM – 12:00 PM
Location: Zoom (Link will be provided upon registration)

In this 1.5-hour session, we will cover:

National Research Platform (NRP): How to create an account, deploy containers, and use managed services like JupyterHub on this global Kubernetes cluster.
Ray on Lawrencium: How to leverage the new Ray module and the Ray Cluster Open OnDemand app for parallel and distributed Python execution.
Please fill out the information below to secure your spot. If you have any questions prior to the event, please contact us at scienceithelp@lbl.gov.

Prerequisite: A user account is preferred but not required.
If you are interested in having an account on the Lawrencium supercluster, please visit our documentation for guidelines.
